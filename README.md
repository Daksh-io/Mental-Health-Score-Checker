# Mental Health Score Checker

A tool to assess and evaluate your mental health based on provided data and metrics.

## Overview

The Mental Health Score Checker is an interactive application designed to help users understand their mental health status by analyzing provided data. It generates a comprehensive mental health score based on various psychological indicators and factors.

## Features

- **Mental Health Assessment**: Evaluate your mental health status through data-driven analysis
- **Score Calculation**: Get a detailed mental health score based on multiple factors
- **Interactive Interface**: User-friendly web interface for easy navigation
- **Data Analysis**: Leverages data science and statistical analysis for accurate results

## Tech Stack

- **Jupyter Notebook** (93.6%) - Data analysis and model development
- **Python** (0.8%) - Backend logic and calculations
- **JavaScript** (1.8%) - Frontend interactivity
- **HTML** (1.8%) - Markup structure
- **CSS** (2%) - Styling and design

## Installation

1. Clone the repository:
```bash
git clone https://github.com/Daksh-io/Mental-Health-Score-Checker.git
cd Mental-Health-Score-Checker
```

2. Install required dependencies:
```bash
pip install -r requirements.txt
```

3. Launch Jupyter Notebook:
```bash
jupyter notebook
```

## Usage

1. Open the Jupyter Notebook files in your browser
2. Follow the prompts to input your mental health indicators
3. Run the cells to generate your mental health score
4. Review the detailed analysis and recommendations
